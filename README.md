# SAÉ 203 - Site Web avec Source de Données

Ce dépôt contient le code source de la SAÉ 203.

## Configuration et Sécurité

> [!IMPORTANT]
> Les fichiers de configuration d'environnement (comme `.env.dev` et `.env.prod`) contenant les identifiants de connexion à la base de données ne sont **pas inclus volontairement** dans ce dépôt Git pour des raisons de sécurité évidentes (protection des mots de passe).
>
> Vous devez créer un fichier `.env.dev` en local basé sur la configuration de votre serveur de base de données.
